# Number Theory Flask App

A Flask web application for number theory tools including factorization, GCD/LCM, modular exponentiation, primality testing, Euler phi, Chinese Remainder Theorem, and chatbot features.

## Project Overview

This project is a web-based math tool platform built with Flask. It allows users to access different number theory calculators through a simple web interface.

The application includes several pages for common number theory operations and supports user-facing templates such as login, registration, profile, and chatbot pages.

## Technologies Used

- Python
- Flask
- HTML
- CSS
- Number Theory
- Web Development

## Features

- Integer factorization
- GCD and LCM calculation
- Modular exponentiation
- Primality testing
- Euler phi calculation
- Chinese Remainder Theorem tool
- Chatbot page
- Login, registration, and profile templates
